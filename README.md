O cliente é uma confeiteira que vende bolos sob encomenda. O sistema registra os pedidos: nome e telefone do cliente, sabor, tamanho, recheio e decoração do bolo, data e horário de entrega, valor total e se o pedido está pago ou pendente. Ele também aplica 30% de acréscimo em pedidos feitos com menos de 24 horas de antecedência. A identidade visual é rosa-bebê e branco, com letras grandes.
